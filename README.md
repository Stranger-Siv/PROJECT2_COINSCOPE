# 🚀 CoinScope

A sleek and responsive web app to track real-time cryptocurrency prices. Built with React, Tailwind CSS, and powered by the CoinGecko API.

## 🌐 Live Demo

🔗 https://coin-scope.netlify.app/

---

## ✨ Features

- 🔍 Search any cryptocurrency by name
- 📊 View live prices, market cap, 24h change
- 👆 Click a coin to expand and see full details
- 💰 Prices shown in USD with INR conversion
- 🎨 Fully responsive and modern UI
- ⚡ Powered by [CoinGecko API](https://www.coingecko.com/en/api)

---

## 🛠️ Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Axios](https://axios-http.com/)
- [CoinGecko API](https://www.coingecko.com/en/api)
